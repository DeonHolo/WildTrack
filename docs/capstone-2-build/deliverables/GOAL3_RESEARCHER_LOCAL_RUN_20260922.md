# Goal 3 researcher-controlled technical run: isolated local verification

**Executed 2026-09-22; repository production baseline `f0e6225`.** This is a locally executed automated backend/database/PDF-parser test with a **mock Google Drive gateway** and separate frontend validation tests. It is **not** a live deployed-app, Google-account, Google Drive provider or browser end-to-end result. No real student/workspace/form/Sheet was read, altered or added to a study cohort. The test account, student, workspace and file references are fictional and exist only in a Spring `test`-profile H2 transaction rolled back at each test's end. The synthetic PDF A/B bytes are generated in memory and parsed by the actual PDF inspection code; DOCX MIME metadata is a deterministic mocked provider response, not a real remote DOCX observation.

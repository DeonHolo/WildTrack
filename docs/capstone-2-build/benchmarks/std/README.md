# WildTrack STD checker benchmark

This folder contains synthetic controlled fixtures for the WildTrack Document Check and AI Review technical benchmark. It is not participant data and it does not prove that real software testing occurred.

## Evaluation authority

The authoritative source remains the owner-supplied private file `docs/STD TEMPLATE.pdf` plus `docs/WildTrack_Document_Validation_Test_Plan.md`.

The source template was inspected with PDFBox on 2026-09-19:

- seven pages;
- body structure: Introduction, Test Plan, Test Cases, Appendix/Test Logs;
- body-page headers still contain `SchedEase`;
- `Testing Tools and Environment` is numbered `3.3` inside the Test Plan chapter;
- the Table of Contents repeats section names that must not count as proof that the corresponding body section exists.

These quirks are preserved as benchmark authority facts. WildTrack must not require `SchedEase`, and it must not turn the numbering typo into a project requirement.

## Fixtures

`manifest.csv` is the frozen answer-key draft. The independent human label-review column intentionally remains `PENDING` until a teammate reviews the expected labels before examining WildTrack output.

`STD-01` is the exact supplied template itself and is referenced in the manifest rather than copied into this tracked folder. The other PDFs are synthetic fixtures generated by `generate-fixtures.cjs`.

Generate the synthetic PDFs from the repository root:

```powershell
$env:NODE_PATH=(Resolve-Path 'frontend/node_modules').Path
node docs/capstone-2-build/benchmarks/std/generate-fixtures.cjs
```

The generator writes only the benchmark fixture directory. It never edits the supplied template.

Run the deterministic fixture regression from `backend` when the owner-supplied template is present:

```powershell
mvn -q "-Dtest=TemplateComparatorTest,StdBenchmarkFixtureTest" test
```

`deterministic-observations.csv` preserves the 2026-09-19 local probe output. It is an observation record, not an independently reviewed benchmark pass rate.

## Scoring boundary

- Deterministic Document Check observations can be run locally and recorded with exact denominators.
- AI Review results require a fresh provider call to count as fresh. Cached results do not count as fresh pilot runs.
- No paid fallback or automatic repeated provider calls are authorized by this benchmark.
- Human answer-key review is still required before treating the expected labels as independently reviewed.
- Results are scoped to synthetic STD fixtures and must not be generalized to all academic documents.
